# AI-Sales-Agent---n8n
This AI-Powered Sales Agent workflow automates outbound prospecting and personalized outreach using Apollo, PhantomBuster, n8n, and MeldFlow. Triggered on a schedule, it fetches and paginates leads from Apollo, enriches contact and company data through LinkedIn scraping, and filters leads with verified emails. The enriched data is then processed by a GPT-4 AI agent to generate personalized ice-breaker messages using profile and company insights. Leads and AI-generated content are stored in Google Sheets for human review and approval. Once approved, the workflow automatically sends personalized outreach emails through MeldFlow using dynamic templates.
Use Case: Automate lead sourcing, enrichment, and personalized cold outreach with an approval-based workflow that ensures high-quality messaging while eliminating manual prospecting and copywriting.
